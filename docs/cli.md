# CLI and REPL contract

`raw "task"` runs one saved turn and exits. `raw` and `raw --interactive` open a `> ` REPL with a saved conversation. `--` ends flag parsing so tasks may begin with `-`. The selected profile, cwd, MCP selections, limits and prompt are fixed when the session starts. Sessions live in the private global state directory and expire after seven days without committed conversation activity by default; `sessions.retention_days` in the canonical global config changes this duration.

`raw --continue [task]` resumes the latest unexpired session for the current workspace. `raw --resume ID [task]` resumes one ID in its saved cwd and prints that cwd. With a task, only the new response is printed on stdout. After a completed one-shot turn, stderr ends with `raw: continue: raw --resume ID "query"`; replace `query` with the next request. If the provider reported complete session usage, a preceding stderr line shows request and input/output token totals, plus cache-read tokens when available. Unknown usage is omitted rather than shown as zero; cache misses are not inferred. Without a task, the latest 20 saved display items are shown before the REPL. A resume reloads the saved config path/profile and current credentials; an explicit different `--config` or `--profile`, a missing cwd/config, or a changed model, endpoint, system prompt, or tool schema is an error. Provider cache reuse after a compatible restart is best effort.

`raw sessions [--all] [--before CURSOR]` lists a bounded page for the current workspace or all workspaces and prints the next cursor. `raw sessions show ID [--before CURSOR]` shows the newest 20 visible items or an older page. `raw sessions delete ID` permanently removes one inactive session; `raw sessions stats` reports database, WAL and payload storage. Listing and viewing do not renew expiry. History keeps complete displayed Bash arguments and CLI result previews, while older full model-only tool outputs can be reclaimed after compact.

Library callers can import `listSessions`, `getSessionHistory({ sessionId, before, limit })`, `resumeSession`, and `deleteSession` from `raw-cli`. Pagination returns the same opaque cursors as the CLI. `resumeSession` takes a compatible provider and tool registry and returns an agent plus a `close()` method that releases its session claim and store; callers must close it when finished.

The CLI streams assistant text to stdout once, in arrival order. Plaintext thinking/reasoning supplied by a provider streams to stderr under `raw: thinking`; providers that return no plaintext reasoning produce no thinking output. Tool activity and automatic compact progress go to stderr. If assistant text has no trailing newline before tool or progress output, the CLI adds one first. A running tool prints its JSON arguments immediately before execution; a call rejected before execution prints a warning with its arguments so the error is diagnosable. `bash` shows the ordered `commands` array, while `write_file` shows operation paths, modes and payload byte counts without displaying `content`, `old_text`, or `new_text`; for an invalid top-level write shape, only argument names appear. Other long argument lists are shortened for display only. On a color terminal, thinking and parameters use dim text, tool names use a cyan accent with a gear icon, and rejected calls use a yellow warning. Redirected output, `NO_COLOR`, and `TERM=dumb` use plain text. A completed turn ends with a newline if streamed text did not already end with one. The four REPL commands must occupy a whole line: `/compact` requests an explicit summary using the selected model (possibly in several bounded chunks); `/clear` closes the old session and starts a new saved ID while leaving old history available; `/stats` shows cumulative request/token/cache fields and unknown coverage without model traffic; `/exit` closes the session. An unknown slash line is ordinary task text. `compact.trigger_tokens` enables automatic compact before an over-threshold inference; without it, compact remains manual.

Every tool result has a status line and a stderr preview. Indexed batch results add an all-status summary before bounded per-row details. The entire displayed result uses at most 10 logical lines: one status line and up to nine content lines. Preview content is also capped at 2,000 Unicode characters, retaining the beginning and end with an explicit omission marker. These display limits do not change the result sent to the model; `--max-output-bytes` controls the separate model-facing cap.

All tools execute automatically with the host account's permissions, including on TTY and non-TTY input. `-y`/`--auto-approve` is a compatibility alias. Ctrl-C aborts active work; in a REPL it returns to `> `, and a second Ctrl-C while idle exits. EOF aborts active work and exits after cleanup. One-shot cancellation exits 130.

Exit codes are 0 for completed turns and informational commands, 1 for runtime/provider errors, 2 for argument/config errors, 3 for max steps, and 130 for user cancellation. Recoverable tool errors that the model handles do not set process exit status. Startup and shutdown close owned MCP clients and running shell processes.
