# Review a repository change

Inspect the actual diff and relevant callers before drawing conclusions. Use the checklist in `references/checklist.md` when the review is broad. Read that relative file with Raw's selected `read_file` tool when needed; its contents are not loaded automatically with this skill.

Report concrete findings with file locations and evidence. Distinguish verified behavior from assumptions. If there are no findings, say what you checked and what remains unverified.
