# Package and share a complete Raw agent

Use `examples/packages/mixed-kit/` as a complete installed source example. It has `raw-package.json` exports for an agent, tool, skill, var, executable provider and MCP server; `files` owns the prompt, helper, skill resource and scripts. A package agent definition omits the author's model alias. It may select own components with `#tools/NAME`, `#skills/NAME`, `#vars/NAME`, and exact nested dependencies with `dep:ALIAS#kind/NAME`. Recipient-specific paths/endpoints/environment names belong in typed `inputs` at permitted whole-value sites, not string interpolation or current var readings.

For an existing configured agent, `raw package export --agent NAME --name @owner/name --version 1.0.0 --out DIR --config AUTHOR_CONFIG` creates editable source and reports included assets, input requirements and unresolved references. Review the output and fix any unresolved asset before distribution. Or author `raw-package.json` and the owned files directly. Run `raw package validate DIR`, `raw package inspect DIR`, then `raw package pack DIR --out FILE.rawpkg`. Give the archive to the recipient through a normal file channel; Raw v1 has no hosted marketplace or automatic Git fetch.

The recipient runs `raw package install FILE.rawpkg --as ALIAS --config CONFIG`, then `raw agent add NAME --from pkg/ALIAS/agents/EXPORT --model LOCAL_MODEL --inputs INPUTS.json --config CONFIG`. The ordinary config owns model/credentials, inputs, overrides and `default_agent`. `overrides` replaces complete blocks/lists; inspect the effective selection before changing it. A direct agent may instead select individual package tools/skills. Exact selected references and required inputs must resolve; unused packages do not block another agent.

`raw package update ALIAS --from NEW.rawpkg --config CONFIG` switches the next attach after checking current bindings. Keep the same session ID; meaningful runtime changes advance its baseline once, and unchanged resumes stabilize. Release labels alone do not rotate the prefix. Roll back by updating from a previous archive. Use `package fork ALIAS --out DIR` to edit source and `package link DIR --as dev` for snapshot-based development. Never distribute the author's session database or claim that an installed package automatically selects components for every agent.
