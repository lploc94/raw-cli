# Share hooks with a Raw package

`raw package export --agent NAME --name @owner/name --version 1.0.0 --out DIR` copies selected hook folders and rewrites agent references to `#hooks/EXPORT`. A hand-authored `raw-package.json` can use `"exports":{"hooks":{"guard":"hooks/guard"}}`, with `files` declaring `hooks/guard` and `requires` containing `raw.hook/2`. `hook.json` and every `./` command/argument asset must be inside the declared tree. A package agent selects `"hooks":{"use":["#hooks/guard"]}`; an exact dependency uses `dep:alias#hooks/guard`.

Run `raw package validate DIR`, `raw package pack DIR --out FILE.rawpkg`, and `raw package inspect FILE.rawpkg`. Install with `raw package install FILE.rawpkg --as kit --config CONFIG`. Bind an exported agent with `raw agent add NAME --from pkg/kit/agents/EXPORT --model RECIPIENT_MODEL --config CONFIG`. A direct agent can select `pkg/kit/hooks/guard` in `hooks.use`. Inspect/install never run hook scripts; a selected runtime event does. Verify in an isolated recipient directory after removing the author's source folder. Update with `raw package update kit --from NEW.rawpkg --config CONFIG`; resume uses the current selected package bytes. Do not distribute machine credentials, session state or outside paths.
